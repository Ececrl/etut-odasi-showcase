# 📚 Etüt Odası

**Ortaokul öğrencileri için odaklanma takibi, çalışma süresi ve yapay zekâ destekli test platformu.**

> 🚧 Proje geliştirme aşamasında. Kaynak kodu özel (private) bir repoda tutuluyor; bu repo projenin tanıtım sayfasıdır.

## Ne yapıyor?

Etüt Odası, öğrencinin evde çalışırken odaklanmasını destekler ve veliye çalışmayı uzaktan takip etme imkânı verir. Öğrenci ve veli için ayrı ekranlar vardır.

**Öğrenci ekranı**
- 📷 **Kamera ile odak takibi:** tarayıcıda yüz algılama ile öğrencinin ekran başında olup olmadığı izlenir
- ⏱️ **Çalışma ve mola yönetimi:** çalışma sayacı, tuvalet/yemek molaları ve mola süresi takibi
- ✅ **AI destekli test:** MEB 7. sınıf kazanımlarına göre ders ve konu seçilerek otomatik test oluşturulur; soru dağılımı öğrencinin çalışma süresine göre ayarlanır
- 📦 **Koleksiyon:** başarılarla kazanılan çıkartmalar (stickers)

**Veli ekranı**
- 🔗 Öğrencinin kamerasına güvenli eşler arası (WebRTC) bağlantı
- 📊 Günlük/haftalık odak ortalaması, toplam çalışma süresi ve çalışılan konu
- 🎁 Öğrenciye ödül gönderme
- 💬 Veli ile öğrenci arasında anlık mesajlaşma

## Teknolojiler

- HTML, CSS, JavaScript
- face-api.js (tarayıcıda yüz algılama)
- PeerJS / WebRTC (öğrenci–veli bağlantısı)
- OpenAI API (test üretimi)
